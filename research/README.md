Staged research project on AI agent security, runtime enforcement and governance assurance, grounded in documented 2026 agent incidents.

Every claim is evidence-graded: P = primary source read in full; S1 = primary source located, not read; S2 = secondary reporting; U = unverified or conflicting.

| 2. Scoping review, gap validation, proposal | Complete; awaiting approval (not a full systematic review) | `stage2/` |
